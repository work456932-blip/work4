# SciMatch

**SciMatch: Impedance-Matched Harness Control for Reliable Scientific Agents**

SciMatch adapts the strength of an agent's harness to the model's capability and the scientific risk of its current execution state. It combines a frozen capability profile, online risk evidence, and remaining reliability and execution budgets to select among five intervention levels (H0–H4).

At each step, a calibrated risk predictor helps the controller choose the least-cost admissible intervention, covering tool interfaces, persistent state, guards, verification, and recovery. The paper develops a conditional task-level risk-accounting result and evaluates SciMatch across four model tiers and five executable scientific-agent benchmarks, including matched-budget comparisons and held-out transfer.
